About this wiki

The protocol page tells the story in plain words; this wiki is the reference behind it. Every page names the files it describes, and the code wins wherever they could disagree: the Rust types and tests in core/, the conformance vectors in core/vectors/ and the TypeScript API in packages/core-api/ describe the current implementation. hoi is preview software, so formats can still change between versions; Releases & verification says how versions are numbered and checked.
